## v0.6

### 新增
- 五个插件的设置页新增「界面语言 / Language」开关，可在**中文**与 **English** 之间切换，切换后设置页与手动选择窗口立即重建，无需重启 Playnite。
- 手动选择窗口、提示文字、搜索无结果的报错信息全部跟随该语言。
- 仓库 README 提供中英双语：`README.md`（简体中文）与 `README.en.md`（English），两页顶部都有语言切换入口。

### 安装
- 下载对应 `.pext` 后拖进 Playnite，或在 Playnite 里「附加组件 → 安装附加组件」选择该文件。
- 也 copy 手动安装：退出 Playnite，把解压出的文件夹放入 `%APPDATA%\Playnite\Extensions`，再启动。

### 已知问题
- Playnite 的「后台下载元数据」不会弹出选择窗口，走自动匹配。
